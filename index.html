Point-to-Segment Distance — Worked Example

BP = Boundary Projection: closest valid point on border segment AB

What are we calculating?

For one candidate border edge AB, find the closest point on that finite segment to query point Q.

1
Use A as the reference point
We do not need BQ here because the segment is written as A + t(B−A). So all movement starts from A toward B.
2
Build direction and query vectors
AB = B − A,   AQ = Q − A
AB gives the edge direction. AQ tells where the query point lies relative to A.
3
Project AQ onto AB
t = (AQ · AB) / |AB|²
t is the fraction along AB: 0 means A, 1 means B, 0.5 means halfway.
4
Clamp and compute BP
BP = A + clamp(t,0,1)(B−A)
Clamp keeps the closest point inside the finite border edge.
Vectors
AB=(6,0), AQ=(3,3)
Projection
t = 18 / 36 = 0.5
BP calculation
BP=(2,1)+0.5(6,0)=(5,1)
Distance
|Q−BP| = 3

What is BSP? Binary Space Partitioning

BSP is a spatial indexing idea: repeatedly divide a 2D space into two subspaces and represent those divisions as a binary tree.
1 · Recursive split

At every depth, choose one split line and divide the current region into two child regions.

2 · Binary tree structure

The split becomes a node. Its left/right children represent the two subspaces created by that split.

3 · Selective traversal

For a query point, visit the nearer child first instead of blindly scanning every boundary element.

BSP idea in one flow

1Pick split axis/line for the current region.
2Separate the map region into left and right subspaces.
3Repeat recursively until small regions remain.
Pakistan map as the reference polygon
First split creates two searchable subspaces on the same map shape.

BSP Construction Rule alternating X/Y median split

Rule used in this presentation

1
Choose axis: axis = depth % 2
2
Sort current points: depth 0 by X, depth 1 by Y, depth 2 by X...
3
Pick median: middle point becomes the current tree node.
4
Recurse: points before median go left, points after median go right.

Algorithm Used: Linear Baseline vs Vertex-Based BSP

The current BSP implementation stores vertices in the tree. Query returns the nearest vertex; then we check its neighboring border edges.

1) Linear baseline — exact but slow

linearDistance(points, Q):
    best = infinity

    for i = 0 to n-1:
        A = points[i]
        B = points[(i + 1) % n]

        d = pointToSegment(Q, A, B)
        best = min(best, d)

    return best
Why exact? Every border edge A–B is checked using projection/clamping.
Cost: for Q query points and N edges → O(Q × N).

2) Vertex-BSP — fast candidate lookup

buildBSP(vertices, depth):
    axis = depth % 2
    sort vertices by x if axis == 0
    sort vertices by y if axis == 1

    mid = vertices.size() / 2
    node.vertex = vertices[mid]
    node.index  = originalIndex

    node.left  = buildBSP(leftHalf, depth+1)
    node.right = buildBSP(rightHalf, depth+1)

queryVertexBSP(root, Q):
    B = nearestVertexFromTree(Q)
    i = B.originalIndex

    A = points[(i - 1 + n) % n]
    C = points[(i + 1) % n]

    d1 = pointToSegment(Q, A, B)
    d2 = pointToSegment(Q, B, C)

    return min(d1, d2)
What BSP gives: nearest vertex B very quickly.
Important: this is fast, but it can miss a closer perpendicular point on a different far edge.
